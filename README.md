# Phantom Terminal 👻

Phantom Terminal is a spooky, interactive terminal experience where users communicate with a mysterious digital ghost through commands.

## Features
- Interactive terminal interface
- Hidden clues and secrets
- Glitch effects and eerie dialogue
- Command history and reset options

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Type `help` to explore the available commands.

## Built With
HTML, CSS, and JavaScript.

## Future Improvements
Integrate an open-source AI model for dynamic conversations.
